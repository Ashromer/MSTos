Aggregated, the geometry organises the ground: hexagons never leave a ninety-degree meeting, so between clusters appear irregular courtyards, streets that narrow and widen, and shaded corners. An orthogonal layout would have produced a field of rows; this one produces a neighbourhood.

El encargo: ofrecer al arquitecto una fachada con una imagen inscrita en la chapa, ya sea un dibujo, una textura o una fotografía, sin dejar de ser una pieza industrial salida de una punzonadora.

What I built: a tool that takes the image, fits it to the real size of the cladding and turns it into a grid of perforations. Each hole's diameter is determined by the greyscale value of that area: it grows where the image is dark and closes where it is light. At a distance the image reads; up close, only perforated sheet.

The output is a DXF with the nesting resolved piece by piece and ready for the machine, Lantek in this case, with the grid pitch, the available diameters and the minimum distance between perforations treated as constraints rather than recommendations.
