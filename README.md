# Portfolio Web de Miguel Suárez Torres

Este es el proyecto de tu página web personal, diseñado para mostrar tus tres principales especialidades profesionales: **Desarrollo de Arquitectura**, **Servicios de Visualización, Renders y Vídeos**, y **BIM Automation & Development**.

## 📁 Estructura del Proyecto

El proyecto está organizado en la carpeta `C_CV_Web` con la siguiente estructura:
- `index.html` — Estructura semántica, contenidos de tu CV extraídos de tus documentos previos, e integraciones de iconos y tipografías modernas.
- `styles.css` — Estilo visual premium con temática oscura, efectos de desenfoque de cristal (glassmorphism), cuadrículas dinámicas y micro-animaciones personalizadas.
- `script.js` — Funcionalidades interactivas, incluyendo el simulador de terminal de pyRevit, el menú móvil responsivo, el sistema de navegación por pestañas de especialidades, el efecto de cursor interactivo y el fondo de partículas animadas basado en Canvas HTML5.

## 🚀 Cómo Visualizarlo en Local

Puedes abrir la web directamente en cualquier navegador moderno:
1. Navega hasta la carpeta `C_CV_Web`.
2. Haz doble clic en `index.html` para abrirlo en tu navegador predeterminado.
3. Alternativamente, si estás usando VS Code, puedes usar la extensión **Live Server** para tener una previsualización interactiva en tiempo real con recarga automática.

## ✨ Características Destacadas

1. **Simulador de Terminal de Python (pyRevit)**: En la sección *BIM Automation & Development*, los usuarios pueden hacer clic en los botones del simulador de consola para ejecutar scripts ficticios en tiempo real (`revit_purge_unused_parameters.py`, `model_integrity_checker.py`, `sheet_creator_xlsx.py`), lo que demuestra tus habilidades de programación de forma interactiva.
2. **Efecto Canvas de Partículas y Retícula**: Un fondo interactivo que responde sutilmente al movimiento del ratón, emulando una red digital y una cuadrícula de modelado paramétrico.
3. **Cursor Personalizado Inmersivo**: Un puntero de diseño premium que se expande y cambia de color al pasar sobre elementos interactivos (desactivado automáticamente en dispositivos móviles para una mejor usabilidad).
4. **Optimización SEO Integrada**: Metadatos descriptivos estructurados para maximizar el índice de búsqueda en navegadores.
5. **Alineación de Marca Personal**: Incorpora tus datos de contacto reales, enlaces a tu portfolio de Issuu y a tu perfil de LinkedIn.
